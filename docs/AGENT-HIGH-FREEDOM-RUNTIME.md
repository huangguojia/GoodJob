# Agent 高自由度执行运行时

## 目标

当明确执行请求没有匹配到现成动作时，不使用无关查询冒充完成。系统先保留用户的复合目标，再允许用户一次启用较长的自主推理流程。

## 运行流程

1. 模型判断本轮语义、对象和授权。
2. 服务端把每个用户要求编译为独立目标与确定性完成证据。
3. 模型优先选择专用工具；能力不足时读取 API 目录和契约。
4. 执行器按中间结果持续规划，直到每个目标都有证据或出现不可推断的真实阻塞。
5. 首轮无法形成可靠执行计划时，界面提供“启用高自由度推理”，不自动扩大外部或破坏性权限。
6. 行动详情展示目标、步骤与完成标准，可保存为待审核的 Skill 调教草稿。

## PI 专项闭环

`解析客户和商机 -> 创建 PI -> 提交审批 -> 有权限时审批 -> 导出 -> 返回文件名和导出任务 -> 用户点击下载`

客户或商机概览、API 目录读取、口头总结均不构成 PI 创建或导出证据。
