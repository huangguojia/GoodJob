# 客户与商机闭环

## 适用目标

客户或线索创建、资料维护、跟进记录、待办安排、商机创建与推进。

## 执行流程

1. 识别目标对象和用户已经给出的字段。
2. 需要关联对象时先查询真实 ID，不得根据名称猜 ID。
3. 专用 Tool 能完成时优先使用专用 Tool；否则先读取 API 契约。
4. 用户明确表示“其他你编”时，自动补齐允许生成的站内字段。
5. 写入后回读对象，核验 ID、关键字段和归属范围。
6. 用户目标包含后续动作时，继续创建跟进或待办，不要停在对象创建。

## 安全补全

- 可使用：未知、待维护、默认阶段、金额 0、合理未来工作日期。
- 不可生成：虚假邮箱、电话、WhatsApp、地址、认证、付款和成交事实。

## 完成标准

- 创建目标取得真实对象 ID。
- 修改目标回读字段一致。
- 关联商机、待办或跟进均已真实落库。
- 最终回复说明创建或修改了什么，以及下一步在哪里查看。

## 失败恢复

- 重复对象：打开已有对象并说明重复依据。
- 缺少可安全补齐字段：按接口默认值继续。
- 缺少不可推断的真实关联对象：只询问一个最关键问题。
- 写入失败：读取接口错误，修正参数后再执行一次。
