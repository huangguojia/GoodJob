# 开发信与客户触达

## 适用目标

生成开发信草稿、发送邮件、发送 Communication 消息、建立有上限的自动跟进序列。

## 执行流程

1. 读取真实客户或线索资料、最近跟进和商机背景。
2. 生成与产品、客户类型和当前阶段相关的内容。
3. 草稿任务保存并打开编辑页面即可完成。
4. 真实发送前锁定收件对象、账号、主题和正文，并执行外部动作确认。
5. 发送成功后回写活动记录，并按用户目标创建下一次跟进。
6. 自动序列需要持续检查回复、退订、失败和停止原因。

## 完成标准

- 草稿：主题和正文已经生成，可在开发信页面编辑。
- 发送：外部接口返回成功，并已写入 CRM 活动记录。
- 序列：已创建序列 ID，发送次数和停止规则明确。
- 后续跟进：待办或提醒已经真实创建。

## 失败恢复

- 无邮箱或 WhatsApp：明确提示缺失，不伪造联系方式。
- 未绑定发送账号：引导到个人配置或 Communication 绑定入口。
- 外部发送失败：保留草稿，展示真实服务错误，不重复发送。
- 收到回复或退订：立即停止后续自动触达。
