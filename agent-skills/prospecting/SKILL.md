# 自动获客闭环

## 适用目标

根据产品、国家、行业和客户类型寻找潜在企业，并持续执行到得到可处理候选。

## 执行流程

1. 合并结构化字段和用户自然语言目标，避免把描述重复变成更强限制。
2. 使用已启用来源创建正式搜索任务。
3. 持续读取任务进度，不能因为任务已启动就宣布完成。
4. 等待来源请求、清洗和候选入池进入终态。
5. 汇总每个来源返回数量、失败原因、清洗去向和可用候选。
6. 用户要求导入时，只转换已经满足人工可联系要求的候选。

## 完成标准

- 搜索任务已经结束或达到用户指定停止条件。
- 返回真实任务 ID。
- 说明原始数量、清洗数量、候选数量和失败来源。
- 用户要求线索时，线索已真实创建并取得 ID。

## 失败恢复

- 单个来源失败：记录真实原因并继续其他来源。
- AI 来源失败：展示模型或适配器真实错误，不使用笼统兜底信息。
- 零结果：放宽非必要限制或切换合法来源，不编造企业。
- 长任务：按间隔持续检查，直到终态或用户取消。
