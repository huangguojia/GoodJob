# Design Context — GoodJob CRM（界面视觉升级）

> 由 impeccable-ui-redesign 技能驱动的配色重构记录。目标：保留现有界面元素（布局/卡片/图标/交互），仅重做视觉配色，去除“AI 味”。

## Users
- 外贸销售（高频，每日录入产品/发货）、销售主管/管理员（看团队视图）、超管。
- 桌面端为主，中文界面。

## Brand personality
- 精准、可信、克制专业（B2B 外贸 SaaS）。
- 行业气质：海运/物流/国际贸易 → 以 ocean teal 传达“可靠、流通、专业”。

## Aesthetic direction
- 参考气质：冷静的青绿单品牌色 + 冷调 tinted 中性色（cool-tinted neutrals），类 Linear/Notion 的克制感。
- 反参考（明确不要）：紫蓝渐变、毛玻璃、网格底纹、默认 Inter 字体、英雄指标卡模板、纯黑纯白。

## Design principles（不可违背）
1. 单一品牌色 `#0f766e`（深青绿），不引入第二对比色；语义色（绿/琥珀/玫红/青）仅用于状态。
2. 中性色带一点 teal 色相（非纯灰），建立潜意识统一。
3. 主按钮/焦点环用品牌色；强调色稀有使用（60-30-10）。
4. 不出现紫、靛、AI 蓝作为装饰色。
5. 字体只用系统中文栈（PingFang SC / Microsoft YaHei），不引入 Inter。

## Palette（当前生效）
- 品牌 `--brand: #0f766e` / `--brand-strong: #0b5d57` / `--brand-2: #115e59` / tint `#e3f3f0`
- 中性 `--bg #f2f6f5` / `--surface #fff` / `--ink #10211f` / `--text #2b3a36` / `--muted #6a7975` / `--line #e1e8e6`
- 侧栏 `--nav #0f1f1d`
- 语义 `--green #15803d` / `--amber #b45309` / `--rose #be123c` / `--aqua #0e7490` / `--violet #64748b`(仅作图表第 4 分类)

## 已知保留（非本次范围）
- `.ai-provider-card` 的各厂商真实品牌色（DeepSeek 蓝 / 智谱紫等）——属厂商身份语义，不改。
- `lead-finder` 模块独立 `--lf-*` 靛紫主题——独立子模块，按需另议。
